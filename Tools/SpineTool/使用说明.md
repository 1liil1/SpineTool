# SpineTool 美术使用说明

适用：Windows 10 / 11，64 位。工具内含预览器及 .NET 运行库。

## 第一次使用

1. 把压缩包完整解压到可写目录，进入 `App` 文件夹双击 `SpineTool.exe`。独立预览则进入 `App/Previewer` 双击 `SpinePreviewer.exe`。请保留整个目录。
2. 在左侧点击“设置 Spine 程序…”，选择本机 Spine 安装目录下的 `Spine.com`。正式导出和预览使用 **Spine 4.1**。
3. 首次启动，导出配置、验证规则的两个下拉框都会自动提供“无”和“齿轮士兵”。无需导入开发电脑上的任务卡片。

Spine 编辑器需要自行安装并正常激活；包内不包含编辑器。已有系统 PATH 配置时，也可以直接使用 PATH 中的 `Spine.com`。

## 导出一个工程

1. 点击“＋ 新建卡片”，填写名称，再选择 `.spine` 工程。
2. 分别选择“导出配置”和“验证规则”。两项互不绑定，例如可以选择美术自定义的导出配置，同时采用项目方提供的“齿轮士兵”验证规则。选择框始终显示；“配置详情”可按需展开。
3. 选择输出根目录。点击输入框或右侧下拉箭头可以选择历史目录，也可以手动输入路径；通过“选择目录”、保存卡片或执行操作会记住目录，最多保留 20 个。
4. 建议勾选“导出 / 验证 / 预览”，然后点击“一键执行”。验证通过后，生成正式输出并启动预览器。
5. 点击“打开输出目录”，打开 **输出根目录下、以当前工程文件名命名的资源文件夹**。尚未输出时，状态栏会提示原因。

例如工程 `D:\Art\Soldier\Soldier.spine`，输出根目录 `D:\Art\Export`，最终资源目录是 `D:\Art\Export\Soldier`，内含 JSON、SKEL、Atlas、PNG。

“导出”按钮单独输出资源，不运行验证；“验证”按钮检查已有资源；“预览”按钮打开已有资源。“一键执行”按勾选项运行。齿轮士兵建议使用完整的一键执行流程，以检查动画和事件。

当前不会覆盖已有的正式资源目录。重复测试时请更换输出根目录，或先自行备份并移走之前的同名资源文件夹。

## 两套内置配置

| 配置 | 导出 | 验证与提示 |
| --- | --- | --- |
| 无 | 官方通用 JSON / Binary 导出模板；使用 Spine Attachments 模式，只打包附件实际引用的图片 | 验证关闭，无动画、事件或骨骼要求 |
| 齿轮士兵 | JSON / Binary 导出；使用 Spine Attachments 模式并启用预乘 Alpha，只打包附件实际引用的图片 | 必须有 `attack` 动画，且该动画中至少有一个 `attack` 事件；缺失时弹窗并阻止正式输出。缺少 `BulletPostion` 骨骼只在日志输出 Warning，不阻断 |

`BulletPostion` 沿用当前项目的实际拼写，注意不是 `BulletPosition`。仅在事件字典声明 `attack`，但没有把它放在 `attack` 动画时间轴上，仍不能通过验证。

齿轮士兵导出还会检查最终 Atlas 的 `pma:true`。出现 PMA 错误时查看日志，确认使用了“齿轮士兵”配置及配套打包设置。

“导出配置”页面顶部的“常用配置”提供缩放、预乘 Alpha、溢出（Bleed）、能被 4 整除和正方形。下面按 Spine 的区域、区域填充、页面、运行时、输出、选项排列，支持最小 / 最大宽高、2 的幂数、Padding、旋转、裁剪空白、Alpha 阈值、过滤和 Wrap 等选项；JSON / Binary 非必要数据和 JSON 美化输出放在“数据导出选项”中。常用区和完整设置中的同名选项会同步，保存和分享时一起带出。Attachments 模式会继续按骨骼实际引用附件筛选图片；页面中的 Atlas 尺寸和 PMA 等设置仍会写入导出配置并生效。Spine 官方说明中，Attachments 模式不会使用图片目录里的 `pack.json` 文件。

内置 Attachments 模式由 Spine 按工程中设置的图片路径查找附件；相对路径按原 `.spine` 工程所在目录解析。请保留实际使用的图片，目录中未被引用的 BG 等文件不会打入图集。

## 导出设置与验证规范分别维护、分享

- “导出配置”页面由美术维护：左侧选择配置，右侧修改 PMA、图集尺寸、缩放等选项，点击“保存导出配置”。
- “验证规则”页面由规范维护者设置：分别填写必需动画、骨骼、插槽、日志警告骨骼和动画事件要求。事件表可以限制次数、时间及时间容差；“阻断错误弹窗”只针对阻断错误。点击“保存验证规则”后生效。
- 在对应页面点击“导出分享文件”，会先保存当前编辑，再生成单个 JSON 文件。导出设置文件名形如 `齿轮士兵.spine-export.json`；验证规则形如 `齿轮士兵.spine-rules.json`。只需要把这个文件发给接收方。
- 接收方进入对应页面点击“导入”，再在工程卡片中选择导入后的配置或规则。导入始终建立独立条目，重名时自动加编号，不覆盖已有内容。分享文件可删除，已导入内容仍然可用。
- 导出设置分享文件会包含 JSON、Binary、纹理打包的依赖参数，Spine 程序路径使用接收方电脑的本机设置。原始工具配置 JSON 也可导入，但导入时需要其相对路径下的依赖文件齐全；原始验证规则 JSON 可直接导入。

本地修改的配置、规则存放在用户数据目录的 `Configurations` 中，重新构建主工具不会覆盖。旧卡片的组合会自动迁移为独立选择；修改一项不会改变另一项。

## 预览与骨骼点检查

- 导出完成后通过“预览”或“一键执行”启动。也可直接双击 `App/Previewer/SpinePreviewer.exe`，再选择资源文件夹。
- 选择文件夹后会递归扫描全部子文件夹。左侧“目录及子目录资源”按相对路径生成资源按钮，同名资源按文件夹区分；可输入名称或子目录筛选，实心圆表示当前资源。每个资源在自己的目录里匹配 Atlas，同名 JSON / SKEL 合并显示；同目录只有一个 Atlas 时允许共用。子目录资源新增、删除或修改后自动刷新，也可手动“重新加载”。
- 左侧动画按钮显示动画名和时长（秒），支持切换 Skin 和播放速度；切换资源后列表随之更新。画面区域可拖动、滚轮缩放。背景颜色可实时修改，支持棋盘背景。
- 骨骼标记默认尝试跟随 `BulletPostion`；也可输入其他骨骼名，点击“跟随骨骼”。红色标记随动画移动，并显示坐标；“取消标记”隐藏标记。
- 画面底部显示动画进度条、当前时间、总时长和百分比。拖动进度条会立即显示对应姿势并暂停；向左右拖动均支持，结束点会保留最后姿势，点击“播放”继续循环。
- 事件按实际时间显示在进度条上，◆ 标记旁标注事件名与时间；点击标记定位到事件时刻，悬停查看 int / float / string 参数。播放经过事件时会高亮。旧的右下角事件日志已移除。
- Previewer 保留自己的目录历史；SpineTool 主界面暂不显示预览历史。

Spine 3.8 导出的数据不能用当前 Spine 4.1 预览器播放，请用 Spine 4.1 重新导出。这里的“版本 4.1”指 major.minor；一般可使用对应的 4.1 补丁版本。

## 任务管理与文件保存

填写卡片的 Tag（多个用逗号分隔）后点击“保存卡片”。左侧可以按项目和多个 Tag 筛选，多个 Tag 同时选中时要求任务包含全部已选 Tag。选中任务会展开卡片；左右区域中间的分隔条可以拖动。

本便携包使用 `App/portable.flag`，卡片、Spine 程序路径、输出目录历史保存在 `App/UserData` 文件夹。需要保留工作记录时，请连同 `UserData` 一起复制；跨电脑后要重新选择本机 Spine 程序、工程和输出目录。配置文件引用使用相对路径，整包移动后可继续读取。

`config` 文件夹随包包含两套导出配置、验证规则及官方导出 / 打包设置。请保留；无需修改配置 JSON 就能使用两套预设。自定义导出配置和验证规则可分别在对应页面点击“从当前配置 / 规则新建”，创建互不影响的副本。

## 常见提示

| 提示 | 处理 |
| --- | --- |
| 找不到 Spine.com / 无法启动进程 | 点击“设置 Spine 程序…”，选择本机安装的 Spine.com |
| Spine CLI 版本不兼容 | 切换到 Spine 4.1 后重新导出 |
| 找不到图片目录 | 检查原工程图片路径和图片文件是否已复制到本机 |
| 缺少 attack 动画 / attack 事件 | 在 Spine 内补齐动画或该动画时间轴上的事件，再重新导出 |
| 缺少 BulletPostion | Warning，不阻断；按项目需求补齐发射骨骼并用标记核对位置 |
| 正式输出目录已存在 | 更换输出根目录，或备份后移走旧的同名文件夹 |
| 预览器加载失败 | 检查数据版本为 4.1，以及 Atlas 引用的全部 PNG 是否与其放在同一目录 |

## 包含的文件

直接打开 `App/SpineTool.exe` 和 `App/Previewer/SpinePreviewer.exe`，无需安装。整体移动解压目录后，仍可直接运行这两个 EXE。

`App/SpineTool.exe` 为主工具；`App/Previewer` 为独立预览器；`App/config` 为内置配置；`Licenses` 为第三方声明。请完整保留 `App` 文件夹内的 DLL 和运行库。使用说明同时提供 HTML，双击 `使用说明.html` 即可在浏览器阅读或打印。

本机验证包含构建、预设与分享文件加载、整包搬移、目录历史、程序启动；风女目录内 5 个资源在 SkeletonAnimation / SkeletonGraphic 两种模式下完成加载切换检查。Attachments 模式已用 Spine 3.8.75 示例工程完成导出验证；未用 Spine 4.1 编辑器完成真实导出验收。

导出和打包模板参考：[Spine 官方 4.1 示例设置](https://github.com/EsotericSoftware/spine-runtimes/tree/4.1/examples/export)。CLI 行为参考：[Spine 官方命令行说明](https://en.esotericsoftware.com/spine-command-line-interface)。
