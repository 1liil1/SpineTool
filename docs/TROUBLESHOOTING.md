# 常见问题与已知限制

## 勾选正方形，图片看起来仍是长条

先区分 PNG 画布与非透明内容。正方形限制页面宽高相等；附件仍可能集中在一条区域中，缩略图不能替代像素尺寸。

1. 勾选后点击“保存导出配置”。
2. 回工程页确认使用刚改的配置，而非同名副本。
3. 使用新输出目录，避免看错旧图。工具不会自动覆盖正式输出。
4. PNG 属性查看真实宽高，或看 Atlas 每个页面的 `size:宽,高`。
5. 找到实际配置文件，核对 JSON / Binary 中 `packAtlas.square` 均为 `true`。二者都启用打包时，后一次 Binary 导出会重写图集，手工改过的旧配置不一致可能影响结果。

本机 Spine 3.8.75 示例，`square: true`、缩放 0.5、最大 1024，实际生成 1024×1024。美术反馈尚未取得原始 PNG 和保存配置，未确认具体环节，也未声称已修复 Spine 4.1 行为。

## 大 BG 导致打包失败

确认 `texturePacker.mode` 为 `EmbeddedAttachments`；未引用的 BG 不因在 images 目录就被打包。若 BG 本身仍是可导出附件，则需按工程需求处理。`Separate` 模式会扫描图片目录，行为不同。

## Spine 版本与预览失败

正式导出选择本机已安装、正常激活的 Spine 4.1 `Spine.com`。工具不提供编辑器。3.8 示例仅验证 CLI 流程，当前预览器不能播放 3.8 数据。

同名 JSON / SKEL 归为一个资源。多 Atlas 按骨架名匹配，仅一份 Atlas 时允许共用。确保它引用的全部页面 PNG 齐全。

## 动画与事件验证不通过

`attack` 是动画名，事件必须实际放在其时间轴，单纯声明事件不够。缺少 `BulletPostion` 仅警告；必需动画/事件缺失会阻断。查看日志的错误代码、目录和文件名。

## 已有正式输出目录

默认不覆盖。换输出根目录，或先备份并移走旧资源。验证失败的临时输出会保留供预览和排查。

提交 Issue 请提供工具与 Spine 版本、脱敏日志、实际像素尺寸和文件清单；不要上传激活信息或不能公开的美术资源。
