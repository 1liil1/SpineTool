# 导出配置与验证规则

导出参数由美术维护，验证规则由规范维护者提供。工程卡片的两个下拉框分别选择，修改一项不改变另一项。

## 导出配置

1. 在“导出配置”选择模板，建议先“从当前配置新建”副本。
2. 设置名称、缩放、PMA、图集尺寸、正方形等。
3. 点击“保存导出配置”。仅勾选但未保存时，CLI 仍使用上次保存的文件。
4. 回工程页选择对应配置再导出。

默认 Attachments 模式按工程引用筛选附件。图片目录中的 `pack.json` 不参与；实际图集参数位于数据导出 JSON 的 `packAtlas`。

“正方形”约束 PNG 页面宽高相等，不要求附件内容填满画布，也不保证用满最大尺寸。透明区域在缩略图中可能不明显，应看 PNG 实际像素与 Atlas 页头 `size`。

缩放 0.5 表示宽高各减半。2 的幂数、4 整除、正方形是页面约束，与最小/最大宽高一起作用。

## 验证规则

支持启用验证、阻断错误弹窗、必需动画/骨骼/插槽、只警告的骨骼、事件最少/最多次数、事件时间与容差、版本、命名正则和文件要求。

内置齿轮规范：必须有 `attack` 动画，且其时间轴至少有一次 `attack` 事件；缺少 `BulletPostion` 仅 Warning；需要 Binary、Atlas、纹理和 4.1 数据。

点击保存后生效。文件要求三态框：勾选为必需，取消为不要求，横线为验证器默认值。

## 配置分享

- 导出参数：导出 `名称.spine-export.json`，包含主配置及 JSON、Binary、图集依赖参数。
- 验证规范：导出 `名称.spine-rules.json`。
- 接收者在对应页面导入，再回工程选择。导入生成独立条目，重名自动编号，不覆盖旧条目。

导入完成后可删除分享文件。接收者使用自己的 Spine 安装路径。原始工具配置 JSON 也可导入，但导入时依赖文件需齐全；原始规则 JSON 可直接导入。

## 数据保存

便携版使用 `App/portable.flag`，个人数据在 `App/UserData`，自定义配置在其 `Configurations` 下。开发版无标记时使用 `%LOCALAPPDATA%/IdleGearDefence/SpineTool`；保留早期路径是为了兼容已有数据。

升级前备份个人数据，不能把空包默认文件覆盖到已编辑配置上。
